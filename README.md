# Grand Theft Car

The official website for **Grand Theft Car**, a retro-style top-down highway racing game for Android.

In **Grand Theft Car**, you drive against the traffic on a fast-paced highway while avoiding incoming vehicles, surviving increasingly difficult stages, and escaping the police after a crash.

This website provides information about the game, its gameplay, stages, features, screenshots, and other game-related content.

## 🏁 Stages

The game features five stages, with each stage introducing a different environment and increasing difficulty.

| Stage | Environment    | Setting |
| ----: | -------------- | ------- |
|     1 | City Highway   | Day     |
|     2 | Countryside    | Sunset  |
|     3 | Mountain Road  | Night   |
|     4 | Desert Highway | Storm   |
|     5 | Neon City      | Night   |

As the stages progress, the game becomes faster and more challenging.

## 🎯 Gameplay

The objective is simple:

**Drive against the traffic and survive as long as possible.**

Change lanes to avoid incoming vehicles. As your speed increases, your reaction time becomes shorter and the traffic becomes more challenging.

If you crash, a police car arrives and begins a pursuit.

Survive the stage to reach the tunnel and complete the stage.

## 🚀 Getting Started

### Requirements

* Node.js
* npm
* Visual Studio Code or another code editor
* Modern web browser

### Run the Website

1. Clone the repository:

```bash
git clone https://github.com/arghobis231/Grand-Theft-Car-Website.git
```

2. Open the project directory:

```bash
cd Grand-Theft-Car-Website
```

3. Install the required dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.

### Build for Production

Create a production build using:

```bash
npm run build
```

The production-ready files will normally be generated inside:

```text
dist/
```

To preview the production build locally:

```bash
npm run preview
```

## ☁️ Deployment

The website can be deployed using **Vercel** or another static web hosting platform.

For Vercel, connect the GitHub repository and use:

```text
Build Command: npm run build
Output Directory: dist
```

Vercel will automatically build and deploy the website.
